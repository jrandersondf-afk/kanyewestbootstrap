CONHECENDO O BOOTSTRAP

Documentação explicativa sobre a ferramenta front-end utilizada no projeto.

O que é Bootstrap?

O Bootstrap é o framework front-end em HTML, CSS e JavaScript mais popular do mundo. Ele fornece uma coleção de componentes pré-estilizados e scripts para facilitar o desenvolvimento de interfaces web modernas e responsivas.

Para que serve?

Ele resolve o problema de ter que construir estilos CSS complexos do zero, garantindo padronização visual, agilidade no desenvolvimento, compatibilidade entre navegadores e adaptação simplificada para diferentes telas (responsividade).

O Sistema de Grid

O sistema de Grid do Bootstrap organiza a tela em até 12 colunas flexíveis. Ele utiliza os seguintes conceitos base:

  • container: Envolve o conteúdo e define as margens e a largura máxima.
  • row: Linha horizontal que engloba as colunas.
  • col: Coluna básica com tamanho automático.
  • col-md-*: Define a quantidade de colunas (de 1 a 12) a partir de telas médias (Tablets/Notebooks).
  • col-lg-*: Formatação específica para telas grandes (Desktops).

Responsividade na Prática

Design responsivo garante que a página funcione perfeitamente em múltiplos dispositivos. O Bootstrap utiliza breakpoints de CSS media queries para adaptar o layout:

📱 Celulares
< 576px
📱 Tablets
≥ 768px
💻 Notebooks
≥ 992px
🖥️ Monitores
≥ 1200px

5 Componentes do Bootstrap Utilizados Neste Projeto

1. Navbar

Menu de navegação responsivo que colapsa em um botão hambúrguer em telas menores.

2. Card

Container flexível utilizado para estruturar os álbuns e momentos da carreira com imagem, título e descrição.

3. Buttons (Botões)

Estilização de botões interativos (ex: btn-outline-warning) com suporte a estados e animações ao passar o mouse.

4. Alert

Caixa de mensagem destacada utilizada na página principal para chamar a atenção do leitor.

5. Badge

Pequenas etiquetas coloridas nos cards para indicar os gêneros e classificações dos álbuns.
